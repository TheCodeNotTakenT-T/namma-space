Serve this folder over HTTP for local preview or HTTPS for visitors. Start at index.html. Opening a file:// URL will not work.

Open Walking setup and choose Enter saved walking setup. Floor, scale, height and entrance are included. Surfaces are rebuilt and the entrance checked before movement.
